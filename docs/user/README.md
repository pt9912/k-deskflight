# Anwender- und Betreiberdokumentation

Dieses Verzeichnis enthält anwender- und betreibernahe Dokumentation:

- Installations- und Bedienanleitungen,
- Runbooks für typische Betriebsfälle,
- Erläuterungen zu Custom Resources, Profilen und Reportformaten.

Diese Dokumente sind keine Architekturartefakte und keine
Spezifikationen. Normative Inhalte gehören in `spec/`, Entscheidungen
in `docs/plan/adr/`.
