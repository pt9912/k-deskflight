und Pläne.

Abgrenzung zu `docs/plan/planning/done/`:

- `done/` = umgesetzt, eingefroren, weiterhin gültig als Referenz.
- `archive/` = verworfen, nicht umgesetzt, oder durch eine neuere
  Entscheidung überholt.
